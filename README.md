# 山顶洞人力训教练

微信端可直接打开的力量训练知识库 + 个体诊断系统。单文件 HTML 应用，无任何外部依赖，全部内容、样式、脚本内联。

## 功能

| 模块 | 内容 |
|---|---|
| 训练原理 | 超负荷、专项性、变异性、疲劳管理、SRA、MEV/MRV 等底层规律 |
| 三大项动作框架 | 深蹲 / 卧推 / 硬拉技术框架，不同资料的分歧观点用对照表比较 |
| 动作问题排查 | 症状 → 原因 → 调整：三大项常见错误与矫正方案速查 |
| 训练计划设置原理 | 计划设计原理 + 14 份训练计划逐一分析与横向对比 |
| 平台期突破 | 停滞原因分类诊断清单与训练/恢复端突破策略 |
| 营养 | 热量与宏量营养素设定、体重解读、补剂 |
| 伤病排查及康复 | 疼痛认知、部位自查、重返训练原则与预防 |
| **个体诊断** | 8 步 60 题问卷 → 63 条规则诊断引擎 → 分级问题清单 + 调整建议 + 计划推荐，支持一键导出 PDF |
| Q&A 智能问答 | 输入问题，按中文分词打分匹配知识库章节并自动展开 |

## 技术特点

- **单文件 SPA**：约 260KB，`file://` 双击即可运行，也可静态托管
- **零依赖**：无框架、无 CDN、无网络请求
- **对比表格冻结首行首列**：`position:sticky` 实现横向滚动时表头与来源列常驻
- **诊断引擎**：规则以条件表达式存储于 `diag_data.json`，前端 `runDiag()` 求值，结果按 P0/P1/P2 分级
- **PDF 导出**：`dPrint()` 生成 A4 打印版样式的新窗口，调用浏览器打印另存为 PDF
- **移动优先**：viewport-fit、safe-area、底部导航，微信内置浏览器可直接使用

## 目录结构

```
.
├── index.html                     # 应用入口（与 山顶洞人力训教练.html 相同）
├── 山顶洞人力训教练.html            # 单文件应用
├── build_app.py                   # 构建脚本：md → HTML
├── diag_data.json                 # 问卷（8步60题）+ 诊断规则（63条）
├── diag_ui.js                     # 诊断模块前端逻辑
├── module_*.md (9 个)             # 知识库内容源文件
└── README.md
```

## 本地运行

直接双击 `index.html`，或起一个静态服务：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 重新构建

```bash
pip3 install markdown
python3 build_app.py     # 输出 山顶洞人力训教练.html
```

- 改 `module_*.md` → 改知识库内容
- 改 `diag_data.json` → 改问卷与诊断规则
- 改 `diag_ui.js` → 改诊断交互与报告样式
- 改 `build_app.py` 内的 HTML 模板 → 改整体界面
